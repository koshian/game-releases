# Japanese Video Game Release Data

日本国内で発売された家庭用ゲームソフトの発売本数を、ハード別・月別に比較するためのデータセットと可視化ツールです。

ファミコンから現行機までの発売日データを複数の公開資料から収集・正規化し、ブラウザ上で月ごとの発売本数をグラフ表示できます。

GitHub Pages では `index.html` をそのまま公開ページとして使用しています。

## できること

* ハードごとの月間ソフト発売本数を比較
* 複数ハードを同じグラフ上に表示
* ファミコンから現行機まで長期間を比較
* Nintendo Switchについて

  * ダウンロード専売を含む全タイトル
  * パッケージ版のあるタイトル
    を別系列として比較
* 元データをCSVとして確認・修正
* CSVから表示用データを再生成

表示用HTMLには個々のゲームタイトルを直接埋め込まず、Gitで管理するCSVから生成した `data.js` を読み込んでいます。

```text

│
├── sources/
│   └── ...
│
└── supplement-raw/
    └── ...
```

### `data/releases.csv`

このリポジトリで使用する、正規化済みの発売タイトルデータです。

基本的にはこのファイルを**人間が確認・修正するための正本**として扱います。

主な列は次のとおりです。

```text
source_id
release_date
title
package
```

例:

```csv
switch,2024-03-14,Example Game,YES
```

`package` は、そのタイトルにパッケージ版が存在するかどうかを示します。

Nintendo Switchの「パッケージあり」系列は、この値を使って生成しています。

### `data/series.csv`

グラフに表示する系列を定義します。

ハード名、メーカー、発売月などに加えて、

* Nintendo Switch 全タイトル
* Nintendo Switch パッケージあり

のような派生系列もここで定義します。

新しい表示系列を追加したい場合は、このファイルを編集してください。

### `data/sources.csv`

各系列のデータソースを管理します。

主に以下の情報を記録しています。

* 資料名
* URL
* 提供者・著者
* 取得日
* データについての注記

グラフ下部に表示される出典情報もここから生成されます。

### `sources/`

収集時に使用した原データや中間データを保存しています。

データの由来を確認したい場合や、正規化処理を再検証したい場合に使用します。

### `supplement-raw/`

既存データセットで不足していた部分を補完するために取得した資料などを保存しています。

### `data.js`

ブラウザ表示用に生成されたデータです。

**このファイルは直接編集しないでください。**

`data/*.csv` を変更したあと、生成スクリプトを実行して更新します。

## グラフを見る

GitHub Pagesで公開されている場合は、そのURLをブラウザで開くだけです。

リポジトリをローカルにcloneした場合も、基本的には `index.html` を直接ブラウザで開けます。

macOSなら例えば:

```sh
open index.html
```

`data.js` は通常の `<script>` として読み込んでいるため、ローカルHTTPサーバーを立てなくても使用できます。

---

## データを修正する

発売日やタイトル名、パッケージ版の有無などに誤りを見つけた場合は、原則として

```text
data/releases.csv
```

を修正してください。

表示用の `data.js` を直接変更しても、次回生成時に上書きされます。

修正後は次のコマンドを実行します。

```sh
ruby scripts/build_viewer_data.rb
```

成功すると、リポジトリ直下の

```text
data.js
```

が更新されます。

その後、

```sh
open index.html
```

などで表示を確認してください。

このスクリプトはRubyの標準ライブラリだけを使用しており、追加Gemは必要ありません。

## データソース

このデータセットは、単一の完全なデータベースから取得したものではありません。

時代やハードによって利用可能な資料が異なるため、複数の公開データを組み合わせています。

主なデータソースには以下があります。

* Wikipedia 日本語版の各ゲームタイトル一覧
* GitHub上で公開されているゲーム発売データセット
* `game-soft` 各種ゲーム機データ
* `sakanaclub` / `laravel-vue-dashboard-dc` 系データセット
* メディア芸術データベース等による確認
* Nintendo Switchなど、既存データに欠落がある期間についての追加調査

具体的なURL、取得日、各データについての注意事項は

```text
data/sources.csv
```

を参照してください。

元データそのものに誤りや欠落がある可能性もあるため、このリポジトリのCSVは「一次資料そのもの」ではなく、複数資料をもとに整理したデータセットです。

## Nintendo Switchの扱いについて

Nintendo Switchでは、ダウンロード専売タイトルが非常に多く発売されています。

そのため、ファミコンやスーパーファミコンなどパッケージ販売が中心だった時代と単純に「発売タイトル数」を比較すると、意味が大きく変わってしまいます。

このリポジトリではSwitchについて、

```text
Nintendo Switch
Nintendo Switch（パッケージあり）
```

の2系列を用意しています。

前者はダウンロード専売を含む全タイトル、後者はパッケージ版の存在を確認できるタイトルのみです。

用途に応じて使い分けてください。

---

## データの注意点

このデータは、ゲーム発売史を完全かつ厳密に確定することを目的とした公式データベースではありません。

特に以下については注意が必要です。

* 発売延期や発売中止作品
* 同一タイトルの通常版・限定版
* パッケージ版とダウンロード版の扱い
* 後発移植・廉価版
* 地域によって発売日が異なる作品
* 同日に複数SKUが存在する作品
* 配信終了タイトル
* 元資料側の重複や記載漏れ
* 現行機の将来発売予定タイトル

可能な限り日本国内での実際の発売日を基準に整理していますが、完全ではありません。

むしろ、誤りを見つけた人が修正できるよう、CSVとGitで管理しています。

## 間違いを見つけたら

**Pull Request や fork を歓迎します。**

発売日、タイトル名、重複、パッケージ版の有無、データソースなど、間違っていると思われる箇所があればぜひ修正してください。

可能であればPRには、修正の根拠となるURLや資料も添えてください。

例えば、

```text
- Nintendo公式サイト
- メーカー公式サイト
- 当時の発売リスト
- Internet Archive
- メディア芸術データベース
- 信頼できるゲーム媒体の記事
```

などがあると確認しやすくなります。
